# 🌐 Web Fundamentals & Interactive Hub

Repositori pembelajaran dasar dan proyek interaktif pertama oleh **Siti Arwiyah**.

Website ini mendemonstrasikan implementasi praktis konsep dasar web development: **HTML5 semantik**, **CSS3 modern (dengan sistem Dark/Light mode)**, serta **JavaScript DOM Manipulation & Web Storage**.

---

## ✨ Fitur Interaktif yang Dibuat

1. 🌓 **Dark & Light Mode Switcher**:
   - Pergantian tema warna visual secara real-time dengan CSS Custom Variables.
   - Menyimpan preferensi pengguna di browser (`localStorage`).
2. 📝 **Target Belajar (To-Do Checklist)**:
   - Tambah tugas belajar baru, centang selesai, dan hapus tugas.
   - Data tersimpan persisten di `localStorage` sehingga tidak hilang saat halaman di-refresh.
3. 🔢 **Click Counter**:
   - Manipulasi state angka (tambah, kurang, reset) dengan perubahan warna dinamis.
4. 🎨 **Random Color Generator**:
   - Menghasilkan kode warna heksadesimal acak dan mengubah styling elemen secara instan.
5. 📱 **Responsive Design**:
   - Tampilan adaptif dan nyaman dibuka di layar HP maupun laptop/komputer.
