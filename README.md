# 🌐 Web Fundamentals

Repositori ini berisi materi pembelajaran dasar dan latihan praktik web development oleh **Siti Arwiyah**.

---

## 📌 Materi yang Dipelajari

1. **HTML5**
   - Struktur dasar & elemen semantik
   - Tabel, list, dan form interaktif
   - Media (audio, video, gambar)
2. **CSS3**
   - Selector, Box Model, dan Typography
   - Layouting modern (Flexbox & CSS Grid)
   - Media Queries & Responsive Web Design
3. **JavaScript (Dasar)**
   - Variabel, tipe data, dan operator
   - Kondisional & perulangan
   - Manipulasi DOM dan event listener

---

## 📂 Struktur Proyek

```text
web-fundamentals/
├── index.html        # Halaman utama latihan
├── styles/
│   └── style.css     # Berkas styling CSS
├── scripts/
│   └── main.js       # Logika interaktif JavaScript
├── .gitignore        # Daftar berkas yang diabaikan git
└── README.md         # Dokumentasi repositori
```

---

## 🚀 Cara Menjalankan

1. Clone repositori ini atau download sebagai ZIP.
2. Buka berkas `index.html` langsung di browser favorit Anda, atau gunakan ekstensi **Live Server** di VS Code.
